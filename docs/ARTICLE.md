# ការបង្កើតឯកសារ API សម្រាប់ KI

KI ជាកន្លែងកត់ត្រាកណ្ដាលនៃ API ឧបករណ៍ និងកម្មវិធី AI របស់ KHOEM-AI។ ទិន្នន័យទាំងអស់ជាឯកសារ JSON ដែលកម្មវិធីផ្សេងៗអានបានតាម `raw.githubusercontent.com` ចាប់ពី `data/index.json` ដោយមិនចាំបាច់ចូលគណនី។ ចំណែកទិន្នន័យឧបករណ៍ពិតៗ រក្សាក្នុងមូលដ្ឋានទិន្នន័យរបស់ KSV ហើយត្រូវចូលគណនីមុនទើបអានបាន។

## ការងារដែលបានធ្វើ

បានបង្កើតឯកសារ `docs/API.md` ដែលពន្យល់ពីរបៀបប្រើទាំងពីរស្រទាប់៖

- បញ្ជីឯកសារ JSON ក្នុង KI និងមុខងាររបស់វានីមួយៗ
- ជំហានចូលគណនី (`/api/auth/login/password`) ការផ្ញើ token និងការបន្តសុពលភាពតាម `/api/auth/token/refresh`
- បញ្ជីរូត API របស់ KSV ចំនួន 128 រូត ចាត់ក្រុមតាមផ្នែក (auth, devices, safety, automation, organizations, billing, ai, gateways ជាដើម)
- ច្បាប់សុវត្ថិភាព៖ គ្មាន secret ឬ IP ក្នុង LAN ក្នុង repo ទិន្នន័យចែកតាមអង្គភាព (organization) ហើយរូតនីមួយៗតម្រូវសិទ្ធិជាក់លាក់

API ទាំងអស់ជារបស់ផ្ទាល់ខ្លួន មិនពឹងលើសេវាខាងក្រៅទេ។ បញ្ជីរូតបង្កើតដោយស្វ័យប្រវត្តិពី `src/server.ts` ដូច្នេះត្រូវនឹងកូដពិត ហើយអាចបង្កើតឡើងវិញបានដោយរត់ស្គ្រីបម្ដងទៀត។

មុន push កូដ `npm run validate` បានឆ្លង (VALID_OK) ហើយ commit មានតែឯកសារ API មួយប៉ុណ្ណោះ (commit b35959a)។

## កំណត់សម្គាល់

អត្ថបទនេះគ្របដណ្ដប់តែឯកសារ API ប៉ុណ្ណោះ។ ទំព័រ KI និង KSV មិនទាន់ត្រូវបានបញ្ចប់ទេ ហើយរូត 128 មិនទាន់បានសាកល្បងម្ដងមួយៗទេ។
