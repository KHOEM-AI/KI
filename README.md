# KI
ទីតាំងកណ្ដាលទុកបញ្ជី API ឧបករណ៍ និងកម្មវិធី AI។ គ្មាន key ក្នុងទីនេះ (key នៅ `.env` ក្នុងម៉ាស៊ីនប៉ុណ្ណោះ)។

- `data/apis.json` បញ្ជី API (ឈ្មោះ key តាម `env_key`)
- `data/devices.json` ឧបករណ៍ទាំងអស់
- `data/ai-apps.json` កម្មវិធី AI

ទំព័រផ្សេងទាញទិន្នន័យពី៖
